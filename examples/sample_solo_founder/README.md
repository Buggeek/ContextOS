# Sample Solo Founder
## One-Person SaaS / Digital Product

Compliance profile: `minimal`

This example demonstrates Context OS applied to a solo founder
building a small digital product.

There is no team.
No bureaucracy.
No enterprise complexity.

The goal is to reduce cognitive load,
externalize context,
and prepare the product for growth.

This example includes only the Minimum Operational Map (MOM).

---

## Founder Context

- Single founder
- One product
- Small user base
- Fast iteration
- AI-assisted development
- High risk of context living only in the founder’s head

---

## Why Context OS Here

Typical solo-founder problems:

- Ideas evolve faster than structure
- Decisions are not recorded
- AI generates inconsistent output
- Adding a collaborator creates friction
- Returning to the project after weeks is costly

Context OS acts as an externalized memory.

---

## Scope of This Example

Included:
- Vision
- Product Map
- System Map
- Core Data Entities
- Minimal governance

Excluded:
- Roadmaps beyond near-term
- Formal workflows
- Automation
- Tooling

This is the smallest viable Context OS implementation.
