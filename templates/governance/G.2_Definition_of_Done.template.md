## DoD Rules (Non-Negotiable)

A work item is “Done” only if:

1. Acceptance Criteria are met.
2. Required tests exist and pass (unit/integration as applicable).
3. No critical regressions introduced.
4. Security/privacy considerations addressed (PII, permissions).
5. Documentation updated (SSOT links, diagrams if needed).
6. Release notes updated if user-facing.
7. Monitoring/observability updated if relevant.
8. QA verification completed (if applicable).
9. Rollback plan considered for high-risk changes.
