# Skillbox

The Skillbox defines the **cognitive capabilities** available to agents operating under the Agentic Operating Model.

Skills are:
- reusable,
- context-agnostic,
- and non-decisional.

They do not own objectives.  
They do not produce final outcomes.  
They **enable reasoning**.

Skills are invoked by roles during missions.

---

## What a Skill Is

A skill represents a stable cognitive capability such as:
- analyzing,
- decomposing,
- synthesizing,
- validating.

A skill:
- does not decide,
- does not interact with users,
- does not execute actions in the external world.

---

## What a Skill Is Not

A skill is not:
- a role,
- a workflow,
- a tool,
- or a prompt.

If a capability requires context-specific judgment, it belongs to a role.  
If it acts on systems, it belongs to the toolbox.

---

## Skill Lifecycle

Skills evolve when:
- a reasoning pattern repeats,
- stabilizes,
- and proves reusable across missions.

Skills are added conservatively.

If a skill increases ambiguity instead of clarity, it should not exist.

---

## Governance

- Skills are shared across all agents
- Skills are versioned
- Skills are evaluated by usefulness, not sophistication

The Skillbox optimizes for **clarity over completeness**.
