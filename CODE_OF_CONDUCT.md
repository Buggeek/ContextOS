# Code of Conduct

Context OS is a professional, structural framework project.

We value:

- Respectful communication
- Constructive criticism
- Intellectual rigor
- Clear argumentation
- Structural thinking

We do not tolerate:

- Personal attacks
- Dismissive behavior
- Low-effort spam contributions
- Structural chaos introduced without discussion

Debate ideas.
Respect people.

Context OS aims to build long-term coherence.
The community must reflect that.
